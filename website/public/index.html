Wallet support

Single-signature, multisig, and watch-only.

01

Create or import a wallet

Create a wallet with new recovery words, restore an existing wallet, or import an extended public key (xpub) to watch cold storage.

02

Hardware wallets

Use supported air-gapped PSBT paths over QR, NFC, SD card, or file. TAPSIGNER can sign supported BIP-84 single-signature and BIP-48 native-SegWit multisig inputs with an intentional NFC tap. See the release notes for new-path physical-validation limits.

03

Your own node and Tor

Connect to your own Electrum server, send wallet traffic through Tor with Orbot, or use Clench offline.

04

Transaction tools

Use coin control, BIP-329 labels, batch payments, RBF bump or cancel, CPFP, saved payees, raw transaction broadcast, and guided sweep or recovery flows.
