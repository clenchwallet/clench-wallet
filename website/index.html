The app

Choose the network, connection, and wallet type.

Start on Mainnet or Testnet, choose how Clench connects to Bitcoin, then create or import a wallet.

Wallet support

Single-signature, multisig, and watch-only.

01

Create or import a wallet

Create a wallet with new recovery words, restore an existing wallet, or import an extended public key (xpub) to watch cold storage.

02

Hardware wallets

Move an unsigned transaction to SeedSigner, Keystone, Passport, Jade, or Coldcard, then bring the signature back over QR, NFC, SD card, or file.

03

Your own node and Tor

Connect to your own Electrum server, send wallet traffic through Tor with Orbot, or use Clench offline.

04

Transaction tools

Choose which coins to spend, freeze coins, pay multiple recipients, raise a fee with RBF, or use CPFP when a transaction is stuck.
