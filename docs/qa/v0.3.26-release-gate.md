## Fail-closed prior candidates

Protected v0.3.24 run
[`30960906412`](https://github.com/clenchwallet/clench-wallet/actions/runs/30960906412)
verified the pinned source tag, built without secrets, signed only the approved
APK, destroyed temporary key material, and created provenance/SBOM
attestations. The independent verifier rejected an unexpected APK v4 `.idsig`
sidecar, so reconstruction and publication were skipped.

Protected v0.3.25 run
[`30970007456`](https://github.com/clenchwallet/clench-wallet/actions/runs/30970007456)
disabled that sidecar and passed isolated signing, key destruction, signature
continuity, and attestation. Its independent verifier then rejected local ZIP
alignment-header differences introduced deterministically by `apksigner`.
Entry contents and compressed streams matched, but the proof did not explain
or reproduce the local-header transformation, so publication was skipped.

No v0.3.24 or v0.3.25 APK or GitHub release was published. Their immutable
signed tags remain historical evidence and must not be moved, deleted, or
repurposed.
