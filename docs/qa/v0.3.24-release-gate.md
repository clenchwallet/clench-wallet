## Residual operational controls

- A separate GitHub identity should approve the release-signing environment;
  the current sole maintainer can also administer the repository.
- Move the production APK key to an offline or hardware-backed signing service
  when practical. Repository changes cannot create that independent custody.
- The embedded BDK Rust dependency graph is not represented by the Maven SBOM;
  audit its pinned upstream Cargo lock separately until upstream publishes
  complete nested-component evidence.
- Physical Keystore security level, biometric invalidation, screenshot/Recents
  behavior, NFC interruption/relay resistance, and hardware-wallet behavior
  require instrumentation or real-device evidence.
