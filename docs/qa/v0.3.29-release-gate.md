## Evidence boundary

This release follows an interrupted audit and scoped defensive corrections.
Neither green tests nor successful signature verification establishes complete
application/native-library security. No key rotation or destructive migration
is permitted. Source-tag creation requires the trusted maintainer key, which
is not available to this server; its public verifier pin is not that key.

Physical camera/QR, NFC and hardware-wallet rows remain NOT RUN. Existing
named hardware deferrals are retained rather than retroactively passed; see
`physical-hardware-gates-v0.3.29.md`. Mac runtime remains NOT RUN because the
host emulator failed before Android started. Hosted emulator results do not
establish physical-device or OEM-wide compatibility.
