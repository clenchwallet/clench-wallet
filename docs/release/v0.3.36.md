# Clench Wallet 0.3.36

This security maintenance update blocks eight compromised emSign certificate
keys when connecting to wallet servers and fetching HTTPS data. The protection
is built into Clench, so it does not depend on a Google Play Services update.
Normal certificate, hostname and explicit wallet-server pin checks remain in
place, including when connecting through Tor.

The native dependency advisory review has also been refreshed through November
8. Sixteen findings concern unused affected native call paths; one unmaintained
build tool remains an explicitly tracked maintenance finding. This does not
mean those libraries were upgraded or every native assurance question is closed.

Wallet keys, transaction handling, database schema, dependencies, native
libraries and release-signing policy are unchanged. Broader physical
hardware-wallet acceptance remains separate from this bounded correction.
