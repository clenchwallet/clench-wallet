# Clench Wallet 0.3.35

This maintenance update keeps send, sweep and raw-transaction broadcast results
associated with the request that started them. Pending requests are reserved
before dispatch, and editing a draft prevents an obsolete result from replacing
its current status. Changing external sweep-address confirmation requires fresh
preparation and review.

The update includes local regressions for request admission, queued cancellation,
completion ownership and retry behavior. Dependencies, native libraries, database
schema and release-signing policy are unchanged. Existing native advisory
applicability dispositions retain their October 16 expiry.

This is a bounded application correction, not a whole-product security clearance.
